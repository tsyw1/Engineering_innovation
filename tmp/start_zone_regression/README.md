# 串口屏启动与两区路线回归检查

从工程根运行 `./tmp/start_zone_regression/run.ps1`，需 PATH 中存在主机版 GCC。
测试编译真实 screen、QR、task_plan、任务1和任务10源码，HAL 与运动接口替换为主机记录器。

- 检查全部254个非启动字节、0x31/0x32、首次命令锁定、重复命令及初始化期间命令保留。
- 经工程现有 HAL UART 回调分发验证 UART5 接线，检查错误字节拒绝、ORE/FE恢复、挂接失败重试和 PRIMASK 恢复。
- 检查未启动时等待超过5秒仍无运动，任务1两区的100mm前进、区1左移1050mm/区2右移1150mm、150mm前进和横移中归零。
- 检查任务1运动/归零失败停车，任务10运动/屏幕刷新失败停车。
- 遍历两区的第一批颜色、第二批颜色、第一批环位排列，共432组返程，加用户的两组任务码及故障用例共440组。
- 检查任务10从实际最后环回中2号环，再左移1900mm，区1后退1050mm或区2前进980mm，并停机刷新统计。

主机检查不替代实车验证；启停区2距离仍需实车校准。
