# 连续地面放置与码垛回归验证

在工程根目录运行 `./tmp/ground_place_regression/run.ps1`，需要可用的主机 GCC。
脚本编译工程中的真实任务3/5/7/9状态机、机械臂控制和视觉细调源码，
用模拟电机、夹爪、底盘、串口和屏幕验证动作衔接，不连接硬件。

覆盖三个任务各自的六种靶环排列（18个正常场景），以及
任务9的六种下层位置排列与六种第二批取料排列（36个正常码垛场景）。
覆盖视觉启动失败、视觉等待超时、电机动作失败和松爪失败，
以及码垛取料前抬升、件间移车、最终抬升、最终回盘旋转、最终关爪
和料盘复位失败（共22个异常场景）。
检查低位移车、松爪稳定时间、停车后识别、视觉对准后取盘料、
物料盘顺序、三次放置计数、最后恢复最高点，以及失败后不继续动作。
同时检查原有放置接口仍然抬升、新接口保持低位、无效参数拒绝执行。
任务9检查同色下层物料映射、物料识别模式、到位后向右15 mm补偿、
件间保持码垛高度和开爪、松爪后稳定100 ms、移车并视觉对准后才抬升取料、
仅8次Z轴旋转和14次升降命令，以及最终高位回盘关爪和料盘回2号位。
检查原码垛接口仍然抬升，新码垛接口保持低位。
检查料盘命令后立即等待400 ms、放置张爪前等待500 ms。

超时场景仅在模拟测试中将视觉超时设置为100 ms，生产配置保持原值。
模拟反馈不代表真实机械间隙、相机识别质量或全程耗时；这些需实车测量。
测试文件位于原有临时目录，不参与STM32固件构建。
